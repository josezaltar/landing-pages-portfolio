# 🚀 Landing Pages para Negócios Locais

Landing pages demonstrativas desenvolvidas para mostrar soluções de presença digital para pequenos negócios: rápidas, responsivas e com foco em conversão pelo WhatsApp.

| Demo | Nicho | Destaques |
|---|---|---|
| [Lumina Odontologia](./clinica-odontologica) | Clínica odontológica | Tratamentos, prova social, agendamento via WhatsApp |
| [Andrade & Moraes](./advocacia) | Escritório de advocacia | Visual sóbrio, áreas de atuação, conteúdo alinhado ao Provimento 205/2021 da OAB |
| [Ateliê da Nina](./confeitaria) | Confeitaria artesanal | Cardápio com preços, fluxo de encomenda, identidade divertida |

![Clínica odontológica](imagens/clinica-odontologica.png)

## ✨ O que cada página entrega

- 📱 Layout 100% responsivo (mobile first)
- ⚡ HTML, CSS e JavaScript puros, sem dependências, carregamento rápido
- 💬 Botões de WhatsApp com mensagem pré-preenchida e botão flutuante
- 🔎 SEO básico: title, meta description e Open Graph
- ❓ Seção de perguntas frequentes com `<details>` nativo (acessível e sem JS)

## 🛠️ Tecnologias

HTML5 · CSS3 (Grid, Flexbox, custom properties) · SVG · Google Fonts · Deploy na Vercel

## ▶️ Como rodar localmente

Basta abrir o `index.html` de qualquer pasta no navegador. Não há build.
